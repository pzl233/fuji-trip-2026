# 日本行程地图

[打开网页地图](https://pzl233.github.io/fuji-trip-2026/)

更新：2026/11/11，本次更新12/4新干线；保留11/10 Torisen确认，其余日期沿用11/08核对记录。15个独立日期（11/26–12/10），分为总结、富士山、东京、大阪，包含已确认、计划、待定与可选安排、住宿和分段交通。

地图采用Leaflet / OpenStreetMap，提供按交通方式生成的Google Maps导航；未知准确位置的活动保留在行程，不猜测坐标。四类图标分别表示餐饮、游玩、住宿和交通，可多选筛选；同一地点同时显示对应的多种用途图标。数字为当天顺序，“选”为备选。地点使用明确的稳定标识合并，不按距离将邻近商店或景点合为一处。

公开文件：index.html、fuji-trip-map.html（相同入口）、trip-style.css、trip-data.js、trip-app.js及文字版itinerary.md。公开数据不含私人确认号或带访问令牌的预订链接。
